Jarvis Privacy Policy

Jarvis is a personal assistant used only by its owner. It accesses the owner's own Gmail account, with the owner's permission, to read, summarize and draft emails for the owner.

Data is processed on the owner's personal computer. It is not sold, shared with third parties, or used for advertising. Google user data is used only to provide these features to the owner, in line with the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at https://myaccount.google.com/permissions.
